# ComfyUI 快速部署测试功能说明

## 项目目标

这个项目用于快速部署和测试 ComfyUI 图生视频工作流，当前重点支持 LTX-2.3 和 Wan 2.2 两类视频生成流程。它不是完整产品服务，而是一个轻量测试工具包，用来把参考图、工作流和运行脚本快速上传到远端 ComfyUI 环境并执行生成测试。

## 当前能实现的功能

### 1. LTX-2.3 图生视频测试

项目内置 LTX-2.3 图生视频工作流，可以用参考图生成 5 秒或 10 秒的舞蹈视频测试结果。

相关文件：

- `assets/beauty_ref.png`：默认参考图
- `workflows/ltx23_i2v_beauty_dancing_5s.json`：5 秒 LTX 工作流
- `workflows/ltx23_i2v_beauty_dancing_10s.json`：10 秒 LTX 工作流
- `runners/run_ltx23_server.py`：服务端运行器，提交工作流到 ComfyUI 并等待结果
- `runners/run_ltx23_api.py`：本地辅助运行器，支持上传参考图并下载结果

### 2. Wan 2.2 图生视频工作流测试

项目内置 Wan 2.2 的 5 秒和 10 秒工作流，可用于在已安装 Wan 2.2 模型的 ComfyUI 环境中测试图生视频能力。

相关文件：

- `workflows/wan22_i2v_beauty_dancing_5s.json`
- `workflows/wan22_i2v_beauty_dancing_10s.json`
- `runners/orchestrate_videos.py`：可按顺序执行 Wan 2.2 和 LTX-2.3 的多个工作流

### 3. 一键上传并执行 LTX 测试

新增的 PowerShell 脚本可以完成快速测试链路：

1. 上传服务端 runner 到远端目录
2. 上传参考图到 `/root/ComfyUI/input/beauty_ref.png`
3. 上传指定时长的 LTX 工作流
4. 在远端执行工作流测试
5. 输出 ComfyUI 生成结果路径

入口脚本：

```powershell
.\deploy\test_ltx23.ps1
```

运行 10 秒版本：

```powershell
.\deploy\test_ltx23.ps1 -Duration 10s
```

指定 ComfyUI 地址：

```powershell
.\deploy\test_ltx23.ps1 -ComfyUIUrl http://127.0.0.1:8188
```

### 4. 远端 SSH/SFTP 上传工具

项目包含轻量 SSH/SFTP 工具，用于部署测试脚本和资源。

相关文件：

- `tools/sftp_upload.py`：上传文件，可选上传后执行命令，上传前会自动创建远端目录
- `tools/ssh_exec.py`：远端执行命令工具

默认通过以下环境变量连接远端机器：

```powershell
$env:SSH_HOST = "你的服务器地址"
$env:SSH_PORT = "端口"
$env:SSH_USER = "root"
$env:SSH_PASS = "密码"
```

### 5. ComfyUI 地址可配置

运行脚本支持通过 `COMFYUI_URL` 指定 ComfyUI API 地址，默认是：

```text
http://127.0.0.1:8188
```

示例：

```powershell
$env:COMFYUI_URL = "http://127.0.0.1:8188"
python .\runners\run_ltx23_server.py
```

### 6. 工作流生成能力

项目保留了工作流生成脚本，用于重新生成或调整 LTX-2.3、Wan 2.2 工作流。

相关文件：

- `generators/gen_ltx23_workflow.py`
- `generators/gen_wan22_workflow.py`

这部分不是快速测试必需路径，但用于后续调整提示词、分辨率、帧数、模型名等参数。

### 7. 模型安装辅助脚本

项目包含 LTX-2.3 模型和节点下载脚本，用于远端 ComfyUI 环境准备。

相关文件：

- `deploy/download_ltx.sh`
- `deploy/download_ltx_extra.sh`

它们主要负责安装 ComfyUI-LTXVideo 节点和下载 LTX-2.3 相关模型。

### 8. 价格/耗时估算辅助

项目包含一个价格计算脚本，用于按工作流运行耗时和机器价格估算生成成本。

相关文件：

- `deploy/price_calculator.py`
- `docs/价格计算.md`

## 工具使用方式

### 1. 你发我工作流 JSON 后能做什么

你可以把 ComfyUI 导出的工作流 JSON 发给我，或者直接放到 `workflows/` 目录。我可以基于这个项目帮你做这些事：

- 检查 JSON 是否能被 Python 正常解析
- 判断它是 ComfyUI UI 格式还是 API prompt 格式
- 整理工作流文件命名，例如 `xxx_5s.json`、`xxx_10s.json`
- 检查里面引用了哪些模型、节点、输入图片和输出节点
- 把固定路径、图片名、模型名改成适合远端测试的版本
- 写一个对应的 runner，让它可以提交到 ComfyUI API 执行
- 把它接入 `deploy/test_ltx23.ps1` 或新增独立测试脚本

推荐你发工作流时同时说明：

```text
这个工作流要跑什么模型：LTX / Wan / Flux / SDXL / 其他
输入是什么：图片 / 文本 / 视频 / 多图
预期输出是什么：图片 / webp / mp4 / gif
希望测试几秒或多少帧
远端 ComfyUI 模型目录里已有的模型文件名
```

如果只是临时测试，可以直接说：

```text
把这个 workflow JSON 接进快速测试脚本，默认用 beauty_ref.png 跑一次。
```

拿到 JSON 后，可以先用分析工具看依赖：

```powershell
python .\tools\analyze_workflow.py .\workflows\xxx.json
```

分析工具会输出：

- workflow 格式：API prompt 或 UI 导出格式
- 节点类型和数量
- 模型文件引用
- 图片/视频输入资源
- 输出节点
- 疑似需要安装的自定义节点

### 2. 怎么上传并运行已有工作流

如果工作流已经在 `workflows/` 里，并且远端 ComfyUI 已经有模型和节点，可以直接用 runner 提交。

本地或远端直接运行：

```powershell
$env:COMFYUI_URL = "http://127.0.0.1:8188"
python .\runners\run_ltx23_server.py .\workflows\ltx23_i2v_beauty_dancing_5s.json
```

通过快速部署脚本上传并执行 LTX 工作流：

```powershell
.\deploy\test_ltx23.ps1
```

运行 10 秒版本：

```powershell
.\deploy\test_ltx23.ps1 -Duration 10s
```

### 3. 怎么下载模型

项目当前提供 LTX-2.3 的模型下载脚本：

```bash
bash /tmp/comfyui-skill-test/download_ltx.sh
bash /tmp/comfyui-skill-test/download_ltx_extra.sh
```

如果在本地通过 SSH 工具让远端执行，可以这样：

```powershell
python .\tools\sftp_upload.py .\deploy\download_ltx.sh /tmp/comfyui-skill-test/download_ltx.sh "bash /tmp/comfyui-skill-test/download_ltx.sh"
python .\tools\sftp_upload.py .\deploy\download_ltx_extra.sh /tmp/comfyui-skill-test/download_ltx_extra.sh "bash /tmp/comfyui-skill-test/download_ltx_extra.sh"
```

这些脚本会处理：

- 安装或确认 `ComfyUI-LTXVideo` 节点
- 下载 LTX-2.3 主模型
- 下载 Gemma-3 文本编码器
- 下载 LTX 蒸馏 LoRA
- 下载可选空间放大器模型

如果你发我一个新 workflow JSON，我也可以从 JSON 里提取模型名，然后补一个专用下载脚本，例如：

```bash
huggingface-cli download <repo_id> <filename> --local-dir /root/ComfyUI/models/<model_type>/
```

常见模型目录对应关系：

```text
checkpoints      -> /root/ComfyUI/models/checkpoints/
diffusion_models -> /root/ComfyUI/models/diffusion_models/
text_encoders    -> /root/ComfyUI/models/text_encoders/
vae              -> /root/ComfyUI/models/vae/
loras            -> /root/ComfyUI/models/loras/
clip_vision      -> /root/ComfyUI/models/clip_vision/
controlnet       -> /root/ComfyUI/models/controlnet/
upscale_models   -> /root/ComfyUI/models/upscale_models/
```

### 4. 怎么下载节点

节点一般下载到：

```text
/root/ComfyUI/custom_nodes/
```

示例：

```bash
cd /root/ComfyUI/custom_nodes
git clone https://github.com/Lightricks/ComfyUI-LTXVideo.git
pip install -r ComfyUI-LTXVideo/requirements.txt
```

通过本地 SSH 工具远端执行：

```powershell
python .\tools\ssh_exec.py "cd /root/ComfyUI/custom_nodes && git clone https://github.com/Lightricks/ComfyUI-LTXVideo.git || true"
python .\tools\ssh_exec.py "cd /root/ComfyUI/custom_nodes/ComfyUI-LTXVideo && pip install -r requirements.txt"
```

如果你发我 workflow JSON，我可以根据里面的 `class_type` 判断可能缺哪些自定义节点，再补安装命令。比如：

```text
LTXVImgToVideo / LTXAVTextEncoderLoader -> ComfyUI-LTXVideo
KSampler / CLIPTextEncode / VAELoader -> ComfyUI 核心节点
SaveAnimatedWEBP -> ComfyUI 核心或视频保存相关节点
```

### 5. 怎么上传文件到远端

上传单个文件：

```powershell
python .\tools\sftp_upload.py .\workflows\xxx.json /tmp/comfyui-skill-test/xxx.json
```

上传并执行命令：

```powershell
python .\tools\sftp_upload.py .\runners\run_ltx23_server.py /tmp/comfyui-skill-test/run_ltx23_server.py "python3 /tmp/comfyui-skill-test/run_ltx23_server.py /tmp/comfyui-skill-test/xxx.json"
```

上传工具会自动创建远端目录。

### 6. 怎么远端执行命令

配置 SSH 环境变量后，可以直接执行远端命令：

```powershell
$env:SSH_HOST = "你的服务器地址"
$env:SSH_PORT = "端口"
$env:SSH_USER = "root"
$env:SSH_PASS = "密码"

python .\tools\ssh_exec.py "nvidia-smi"
python .\tools\ssh_exec.py "ls -lh /root/ComfyUI/models/checkpoints"
python .\tools\ssh_exec.py "curl http://127.0.0.1:8188/system_stats"
```

### 7. 新工作流接入推荐流程

当你给一个新的 ComfyUI workflow JSON 时，推荐按这个流程处理：

1. 放入 `workflows/`
2. 检查 JSON 格式和节点类型
3. 提取模型文件名和缺失节点
4. 补模型下载脚本或节点安装命令
5. 写或复用 runner 提交到 ComfyUI API
6. 上传参考图和 workflow 到远端
7. 执行一次小参数测试
8. 成功后再跑正式参数

## 快速测试推荐流程

### 第一步：配置远端连接

```powershell
$env:SSH_HOST = "你的服务器地址"
$env:SSH_PORT = "端口"
$env:SSH_USER = "root"
$env:SSH_PASS = "密码"
```

### 第二步：确认远端 ComfyUI 已启动

远端 ComfyUI 默认需要监听：

```text
http://127.0.0.1:8188
```

如果不是这个地址，运行测试时传入 `-ComfyUIUrl`。

### 第三步：执行 LTX 5 秒测试

```powershell
.\deploy\test_ltx23.ps1
```

### 第四步：执行 LTX 10 秒测试

```powershell
.\deploy\test_ltx23.ps1 -Duration 10s
```

## 当前项目边界

当前项目适合做快速部署验证和工作流测试，不包含以下能力：

- 不提供 Web UI
- 不提供 OpenAI 兼容 API 服务
- 不自动安装完整 ComfyUI 环境
- 不自动检测所有模型是否存在
- 不负责长期任务队列管理
- 不提供多用户权限或生产级服务治理

## 最小部署包建议

如果只是为了快速测试，核心文件只需要保留：

```text
assets/
workflows/
runners/
tools/
deploy/test_ltx23.ps1
```

如果需要准备模型环境，再加上：

```text
deploy/download_ltx.sh
deploy/download_ltx_extra.sh
```

如果需要重新生成工作流，再保留：

```text
generators/
```
