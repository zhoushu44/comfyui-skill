# ComfyUI 生成价格计算器

## 概述

本文档记录 ComfyUI 工作流的生成成本计算结果，用于估算视频/图片生成的实际价格。

**计算方式**：运行指定工作流 3 次，排除首次模型加载时间，取后 2 次的平均耗时计算单价。

**价格公式**：
```
单个视频价格 = (平均耗时秒数 / 3600) × 每小时价格
```

---

### 通用参数

| 参数 | 说明 | 默认值 |

| 运行次数 | 总运行次数（第 1 次为模型预热，不计时） | 3 |

## 使用方法

### 1. 触发计算

对 AI 说"计算"、"算价格"、"成本计算"等关键词，AI 会询问每小时价格。

### 2. 提供价格

```
用户: 计算
AI: 请问 GPU 服务器多少钱每小时？（单位：元/小时）
用户: 2.5
```

### 3. 选择工作流

```
AI: 要测试哪个工作流？
    - wan22_i2v_5s（Wan 2.2 图生视频 5s）
    - wan22_i2v_10s（Wan 2.2 图生视频 10s）
    - ltx23_i2v_5s（LTX-2.3 图生视频 5s）
    - ltx23_i2v_10s（LTX-2.3 图生视频 10s）
用户: wan22_i2v_5s
```

### 4. 运行计算器

AI 通过 SSH 在服务器上运行价格计算器：
```bash
python3 /opt/comfyui-adapter/price_calculator.py /tmp/wan22_i2v_beauty_dancing_5s.json 2.5 3
```

### 5. 查看结果

计算完成后，AI 将结果填入本文档的"实际测量结果"章节，并展示：
```
价格计算结果：
- 工作流: Wan 2.2 图生视频 5s
- 有效计时: 2 次（排除首次模型加载）
- 平均耗时: XX.X 分钟
- 每小时价格: 2.5 元/小时
- 单个视频价格: X.XX 元
```

## 计算说明

| 项目 | 说明 |
|------|------|
| **为何排除第 1 次** | 首次运行需加载模型到显存（如 Wan 2.2 14B 需 10+ 分钟加载），不反映真实生成速度 |
| **运行次数** | 默认 3 次（1 次预热 + 2 次计时），可自定义 |
| **计时范围** | 从提交工作流到输出文件生成完成（含 VAE 解码，不含模型加载） |
| **价格公式** | `单个价格 = (平均耗时秒数 / 3600) × 每小时价格` |
| **适用场景** | 图片生成、视频生成、任何 ComfyUI 工作流 |
| **注意事项** | 计算期间不要提交其他任务；显存不足时系统会自动卸载/重载模型影响精度 |

## 价格计算器脚本

脚本位置：`/opt/comfyui-adapter/price_calculator.py`（服务器端）

本地副本：`price_calculator.py`

**用法**：
```bash
python3 price_calculator.py <工作流路径> <每小时价格> [运行次数]
```

**示例**：
```bash
# 测试 Wan 2.2 5s，每小时 2.5 元，运行 3 次
python3 price_calculator.py /tmp/wan22_i2v_beauty_dancing_5s.json 2.5 3

# 测试 LTX-2.3 10s，每小时 3.0 元，运行 5 次
python3 price_calculator.py /tmp/ltx23_i2v_beauty_dancing_10s.json 3.0 5
